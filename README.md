# Verifiabl Ruby SDKs

This repository holds the Verifiabl Ruby SDKs. Each gem is in `gems/`.

- [`verifiabl-issuer`](gems/verifiabl-issuer): the issuer SDK, published as [verifiabl-issuer](https://rubygems.org/gems/verifiabl-issuer) on RubyGems.
- [`examples/issuer`](examples/issuer): runnable issuer examples.

Documentation is at [docs.verifiabl.io](https://docs.verifiabl.io/issuer-sdk?lang=ruby). To build and test the gems, see [DEVELOPMENT.md](DEVELOPMENT.md).
