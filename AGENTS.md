# AGENTS.md — Verifiabl Ruby SDK

Ruby SDK repository for Verifiabl. Each independently published gem lives under `gems/`; the
issuer/provider-side SDK is in `gems/verifiabl-issuer`. Keep it framework-neutral: do not add a
runtime dependency on or integration layer for Rails or Active Support. QR matrix generation uses
`rqrcode_core`; Verifiabl owns deterministic SVG and PNG badge rendering. Keep this repository
self-contained and compatible with Ruby 3.3 and newer.

Canonical PII profile constants, fixtures, QR frame widths, frame assets, and rendering parity
fixtures are generated by shared canonical tooling. Do not edit generated files by hand.

## Review gates

```sh
bundle exec standardrb
bundle exec rake metrics
bundle exec rake test
(cd gems/verifiabl-issuer && bundle exec gem build verifiabl-issuer.gemspec)
bundle exec ruby script/packed_gem_check.rb
```
